How to use Vero Designer

      
    

    

      
    
        
  1. Choose a component, then click the schematic grid. Every part receives an automatic ID such as R1, C1, Q1, or U1.
    2. 
        
  2. Select Wire. Click the first pin and then the second pin. Connecting another pin to any pin already on that net creates a branch.
    3. 
        
  3. Place INPUT, OUTPUT, 9V, GND, or a custom net label. Labels with the same name are electrically merged. A selected label can be set to Offboard for an edge connection or Onboard for internal naming only.
    4. 
        
  4. Select a component to change its value or model, rotate it, duplicate it, or inspect the net on each pin. Hold Ctrl/Cmd while clicking to select several components, or press Ctrl/Cmd+A to select the complete schematic for group movement.
    5. 
        
  5. Click a schematic wire in Select mode, then drag its cyan route handle to move the middle section around components while keeping both endpoints connected.
    6. 
        
  6. Press Generate Vero. The area-first router searches for the best compact layout without ever exceeding the selected maximum number of columns.
    7. 
        
  7. On the Vero page, drag the middle of any component to move the whole part. Resistors, capacitors, diodes, and links also have draggable pin handles. Track cuts can be dragged directly to another unused hole. Drag the cyan notch at the board’s bottom-right corner to shrink or expand the board itself.
    8. 
        
  8. The copper-strip colors recalculate after every valid edit. Red strip coloring means the physical edit has shorted two schematic nets; the Vero editor panel also reports split nets.
    9. 
      

      
Useful shortcuts

      
F1 selects the Select tool, F2 selects the Wire tool, Ctrl/Cmd+A selects every schematic component, Ctrl/Cmd+click toggles individual components in the selection, Ctrl/Cmd+C copies the selection, Ctrl/Cmd+V pastes it, Delete removes the selected component/s, R rotates a selected part or the active placement preview, F flips/mirrors the selected component/s, and Esc cancels the active action without changing tools. On the Vero page, Ctrl/Cmd+Z and Ctrl/Cmd+Y undo and redo manual layout edits.

      
Manufacturing note

      
The generated board is a deterministic heuristic proposal, not a substitute for electrical-rule checking. Verify pinouts, strip cuts, component packages, current ratings, clearances, and polarity before building hardware.
